# rorweb - Rigs of Rods in your browser

A web port of [Rigs of Rods](https://github.com/RigsOfRods/rigs-of-rods) (soft-body vehicle physics game) that runs from a single HTML file. **Ported by Down1oads.**

## Play
1. Open the **Releases** page and download `Rigs_of_Rods_single.html` (about 224 MB).
2. Double-click it (desktop Chrome or Edge recommended). Loading takes a little while.

## Features
- Keyboard controls: W/S gas and brake, A/D steer, Shift/Ctrl change gear, E engine, F1 shows all controls
- Install mods by adding `.zip` files from the **Mods** menu (saved in your browser)
- Browser-to-browser multiplayer with a 6-digit code (needs internet)

## Notes
- Needs a PC that runs WebGL 2 well and about 2 GB free memory.
- Multiplayer uses ntfy.sh only to swap connection details for the code, then connects directly.
- Shadows can be turned off in Settings > Graphics if the game is slow.
